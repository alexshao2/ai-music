# Soul — Cookbook đầy đủ

Soul music sinh ra từ giao thoa **gospel + R&B + blues** tại Mỹ 1950–60s. Từ Motown (Stevie
Wonder, Marvin Gaye, The Temptations) đến Stax/Memphis Soul (Otis Redding, Sam & Dave),
Philadelphia Soul (The O'Jays), rồi Neo-Soul 1990–2000s (D'Angelo, Erykah Badu, Lauryn Hill),
và Modern Soul/Retro Soul 2010+ (Leon Bridges, Silk Sonic, Anderson .Paak, Lianne La Havas).
Đặc trưng xuyên suốt: **vocal emotion cực mạnh**, gospel-rooted harmony, live instrumentation,
và groove organic.

## 1. Tham số âm thanh

| Tham số | Giá trị |
|--|--|
| Tempo | 65–120 BPM. Slow soul 65–80; mid-tempo groove 85–100; uptempo 105–120 (Motown) |
| Time sig | 4/4 (~90%); 6/8 (slow soul ballad); 12/8 (gospel feel) |
| Key | Major dominant ~60% (C, D, Eb, F, G, Ab) — soul thường "hopeful"; minor cho introspective |
| Vocal range | Nữ C4–G5 (Aretha belt); nam C3–A4 (Marvin falsetto to D5) |
| Master loudness | −12 đến −8 LUFS (vintage analog warmth, dynamic) |
| Tape saturation | Có — analog warmth là signature |

## 2. Cấu trúc bài (form)

### Classic soul (Motown era)
```
Intro (4–8, horn stab hoặc guitar riff)
→ Verse 1 (8–16)  →  Chorus (8, strong hook)
→ Verse 2 (8–16)  →  Chorus
→ Bridge (8, vocal ad-lib hoặc instrumental)
→ Chorus (repeat 2–3× fade out)
```

### Neo-soul / modern soul
```
Intro (4–8, groove establish)
→ Verse 1 (16, talk-sing intimate)  →  Pre-chorus (4–8)
→ Chorus (8–16)  →  Verse 2 (16)
→ Pre-chorus  →  Chorus
→ Bridge (8–16, vocal showcase / instrumental solo)
→ Final Chorus (16, ad-libs + vocal stacks)
→ Outro (8–16, vamp + ad-lib fade)
```

**Fade-out outro** vẫn rất phổ biến trong soul — giữ lại từ truyền thống Motown.

## 3. Vòng hợp âm điển hình

| Tên vòng | Pattern | Ví dụ |
|--|--|--|
| Motown classic | I–vi–IV–V | C–Am–F–G. Happy, driving. |
| Gospel turnaround | I–I7–IV–iv | C–C7–F–Fm. Major→minor IV. Emotional pivot. |
| Soul ii–V–I | ii7–V7–Imaj7 | Dm7–G7–Cmaj7. Jazz-soul standard. |
| Neo-soul Dorian | i7–IV7 (vamp) | Em7–A7. D'Angelo/Erykah. Groove-based. |
| Silk Sonic retro | I–iii7–vi–II7–V | C–Em7–Am–D7–G. Extended cycle. |
| Minor soul | i–iv–bVII–bIII | Am–Dm–G–C. Melancholic groove. |
| Philly soul lush | Imaj9–iii7–vi9–ii7–V7 | Long cycle with 9th voicings. Orchestral feel. |
| Blues-soul | I7–IV7–I7–V7 | 12-bar blues compressed to 4-bar. Raw. |

**Voicing**: dùng **chord 7/9/11/13** như R&B nhưng soul thường **thêm suspension (sus2/sus4)** và **added 6th (6/9)** — C6/9 (C–E–G–A–D) rất đặc trưng Motown.

## 4. Phối khí per section

| Section | Lớp âm thanh |
|--|--|
| Intro | Horn section stab (trumpet + tenor sax + trombone) hoặc guitar riff (Stax). Drum count-in. |
| Verse | Electric guitar (Strat clean, neck pickup, wah optional), bass guitar (Fender P-bass fingerstyle, deep pocket), drums (kick+snare+hi-hat live, shuffle feel), organ (Hammond B3 Leslie) pad. |
| Pre-chorus | Add tambourine, strings swell (violins + violas), piano (Wurlitzer/Rhodes) arpeggio thay vì block chord. |
| Chorus | Full horn section (trumpet melody + sax harmony + trombone bass), string section (violins + violas + cellos), backing vocal choir (3–4 part gospel), tambourine, full drum kit. |
| Bridge | Strip-down: vocal + organ sustain. Hoặc instrumental solo (guitar wah, sax solo, piano solo). |
| Final Chorus | Everything + vocal ad-lib gospel runs + horn counter-melody + tambourine double-time + drum fills. |
| Outro | Vamp chorus chords + vocal ad-lib/shout fade-out. Hoặc horn riff outro. |

**Drum kit**: acoustic live kit — kick (felt beater mềm), snare (gut snare, warm crack), hi-hat (14" thin), ride. Ghost notes trên snare RẤT quan trọng.

**Bass**: Fender Precision hoặc Jazz Bass, fingerstyle, deep in the pocket, walking hoặc 1/8 groove. Bass line melodic — không chỉ root note.

## 6. Vocal style

- **Gospel-rooted belting** — full chest voice, powerful emotional delivery (Aretha, Adele-soul)
- **Melisma / vocal runs** 5–12 nốt — signature soul technique, ở cuối phrase, bridge, ad-lib
- **Call-and-response** — lead singer call, backing choir responds (gospel tradition)
- **Vibrato tự nhiên** — wide, warm, 5–6 Hz (không chỉnh pitch quá mức)
- **Dynamic range LỚN** — whisper verse → belt chorus → scream ad-lib
- **Falsetto switch** — nam chuyển chest→falsetto (Marvin Gaye, D'Angelo, Silk Sonic)
- **Backing vocals**: 3–4 part harmony, gospel block chord, "ooh"/"ahh" pad
- **Reverb**: plate reverb 1.5–2.0s (vintage), tape delay 1/4 note
- **Compression**: moderate 3:1 — giữ dynamic range

## 7. Lyric idiom

- **Theme**: love (romantic, sensual, heartbreak), social justice (Marvin Gaye, Stevie Wonder), empowerment, spiritual, gratitude, community
- **Tone**: sincere, passionate, preachy khi social; tender khi love
- **POV**: "I" dominant; "we" cho collective/anthem
- **Imagery**: Sunday church, mama's kitchen, river, highway, hometown, rain, sunshine
- **Hook**: melodic, repetitive, anthemic — thường 4–6 words singalong
- **Verse-chorus contrast**: verse kể chuyện → chorus tuyên bố / cảm xúc mạnh
- **Gospel language**: "Lord", "mercy", "hallelujah" khi spiritual influence rõ
- **Rhyme**: clean end-rhyme (AABB hoặc ABAB), ít internal rhyme phức tạp như rap

## 8. Suno style tag template

Classic soul:
```
classic soul, motown, 104 bpm, c major, horn section, tambourine, fender bass,
warm live drums, gospel backing vocals, powerful female belt vocal, vintage analog warmth
```

Neo-soul:
```
neo-soul, 72 bpm, d major, rhodes electric piano, fender precision bass,
live drums with ghost notes, warm male vocal with falsetto, gospel harmony,
tape saturation, intimate groove
```

Modern retro soul (Silk Sonic style):
```
retro soul, 70s soul revival, 110 bpm, e flat major, horn section brass,
string section, clavinet, funky bass guitar, live drums with tambourine,
smooth male duet vocal, doo-wop harmonies, analog warmth
```

## 9. DON'T

- KHÔNG dùng 808/programmed drums làm chính — soul = live drums (hoặc programmed nghe live).
- KHÔNG auto-tune heavy — soul cần vocal thật, imperfection là beauty.
- KHÔNG skip horn section / strings khi full arrangement — đây là signature soul texture.
- KHÔNG để bass line chỉ root note — soul bass PHẢI melodic, walking.
- KHÔNG nhầm soul với R&B hiện đại — soul organic/live hơn, R&B modern electronic/programmed hơn.
