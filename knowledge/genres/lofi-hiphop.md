# Lo-fi Hip-Hop — Cookbook đầy đủ

Lo-fi hip-hop là dòng nhạc chillout kết hợp **boom-bap drums + jazz samples + analog imperfections**
(tape hiss, vinyl crackle, wow/flutter). Gốc từ producer culture: J Dilla (Donuts), Nujabes
(Modal Soul), MF DOOM. Bùng nổ streaming 2017+ qua kênh **Lofi Girl** (24/7 livestream).
Đặc trưng: KHÔNG vocal (instrumental dominant), mood "study/chill/relax", short loops 2–3 phút,
aesthetic mộc ý chủ đích.

Biến thể: **chillhop** (uptempo hơn, 85–95 BPM), **lo-fi jazz** (jazz dominant), **lo-fi ambient**
(atmospheric, minimal drums).

## 1. Tham số âm thanh

| Tham số | Giá trị |
|--|--|
| Tempo | 70–90 BPM (sweet-spot 75–85). Chillhop lên 90–95. |
| Time sig | 4/4 (~95%); swing feel 60–70% |
| Key | Major dominant ~60% (C, D, Eb, F, G) — "warm" feel; minor cho moody (Am, Em, Dm) |
| Vocal | Không có vocal chính (~90% instrumental). Sample dialogue film/anime hoặc vocal chop. |
| Master loudness | −16 đến −12 LUFS (giữ dynamic, KHÔNG loud) |
| Noise floor | Vinyl crackle ở −30 đến −40 dB — có mặt xuyên suốt, rất nhẹ |
| Tape saturation | Có — analog warmth, slight distortion |

## 2. Cấu trúc bài (form)

Lo-fi KHÔNG có verse-chorus. Thường loop-based, đơn giản:

```
Intro (4–8 bar, filtered/muted — eased in)
→ Theme A (16 bar, main melody + full groove)
→ Variation (16 bar, same groove + add/subtract 1–2 elements)
→ Theme A return (16 bar)
→ Outro (4–8 bar, filter out / fade / vinyl noise tail)
```

Biến thể phức tạp hơn:
```
Intro (4)  →  A (16)  →  B (16, new melody)  →  A' (16)  →  B' (8)  →  Outro (4–8)
```

**Duration**: 1:30–3:00 phút. Ngắn, loop, playlist-friendly.

**Section transition**: dùng drum fill NHẸNH, hoặc chỉ thêm/bớt 1 layer. Không có build-up/drop dramatic.

## 3. Vòng hợp âm điển hình

Lo-fi = jazz chords chậm:

| Tên vòng | Pattern | Ví dụ |
|--|--|--|
| Lo-fi major 7 | Imaj7–vi7–ii9–V7 | Cmaj7–Am7–Dm9–G7. Jazz standard loop. |
| Lo-fi minor | i9–iv9–bVII7–bIIImaj7 | Am9–Dm9–G7–Cmaj7. Smooth, melancholic. |
| Dorian chill | i7–IV7 (2-chord) | Em7–A7. Minimal, groove-based. |
| Lydian float | Imaj7–IImaj7 | Cmaj7–Dmaj7. Dreamy, floating. |
| Circle of 4ths | Imaj7–IVmaj7–bVIImaj7–bIIImaj7 | Fmaj7–Bbmaj7–Ebmaj7–Abmaj7. Smooth descent. |
| 2-5-1 jazz | ii7–V7–Imaj7 | Dm7–G7–Cmaj7. Resolved, warm. |
| Bossa nova feel | Imaj7–ii7–iii7–IV7 | Cmaj7–Dm7–Em7–F7. Bossa-lofi. |
| Suspended | Imaj7–IVsus2–vi–IIadd9 | Floating, unresolved feel. |

**Voicing**: **extended jazz chord** bắt buộc (7th/9th/11th/13th). Triad = quá "pop" cho lo-fi.
**Closed voicing** trên piano/Rhodes, **drop-2** cho guitar.

## 4. Phối khí per section

| Element | Chi tiết |
|--|--|
| Keys (primary) | **Rhodes EP** (Fender Rhodes Mark I hoặc II) hoặc **Wurlitzer** — main harmonic instrument. Chơi chord block + occasional melody. Warm, bell-like tone. |
| Piano | Grand piano (Steinway type) — alternative to Rhodes. LP filtered ở 8–10 kHz cho warmth. |
| Guitar | Nylon/classical guitar fingerpicked, hoặc electric guitar clean jazz tone (neck pickup, warm). Occasional. |
| Drums | **Boom-bap style**: kick mềm (felt, round), snare/clap nhẹ (ghost notes nhiều), hi-hat swing 1/8 (mở/đóng alternate). Vinyl sample drum loops phổ biến. |
| Bass | Round, deep, warm — dưới 100 Hz. Sub bass synth hoặc upright bass sample. Simple root-5th. |
| Vibraphone / Glockenspiel | Lấp lánh texture — 1–2 note accents, không chơi liên tục. |
| Vinyl noise | Crackle + hiss ở −30 đến −40 dB — xuyên suốt. |
| Tape FX | Wow/flutter nhẹ trên Rhodes/sample — tạo "cũ, ấm". |
| Samples | Film dialogue (anime, old movie), nature sounds (mưa, sóng biển), ambient pad nhẹ. Đặt thấp background. |
| Percussion | Shaker, tambourine, finger snap — optional, rất nhẹ. |

## 5. Production techniques (chi tiết)

### Analog imperfections (core aesthetic)
- **LP filter**: cắt high freq ở 8–10 kHz → mọi thứ nghe "warm, muted"
- **Vinyl crackle**: iZotope Vinyl plugin hoặc sample loop ở −30 đến −40 dB
- **Tape saturation**: Aberrant DSP SketchCassette, RC-20 Retro Color, hoặc Goodhertz Lossy
- **Wow/flutter**: pitch wobble nhẹ (±5–10 cent, random, slow LFO)
- **Bit reduction**: optional — 12-bit hoặc 16-bit feel

### Drums
- **Sample-based**: chop từ vinyl jazz/soul records, hoặc dùng SP-404/MPC style
- **Swing**: 60–70% swing trên hi-hat/snare
- **Velocity humanize**: ±15–20% random velocity
- **NO sidechain mạnh** — lo-fi cần cảm giác "phẳng êm", không pumping
- **Ghost notes**: snare ghost 1/16 cực nhẹ tạo groove

### Mix
- **KHÔNG loud** — target −16 đến −12 LUFS
- **Stereo width vừa**: Rhodes panned center hoặc slight L/R; drums center; sample wide
- **Reverb nhẹ**: plate 0.8–1.2s, low mix (15–25%)
- **Delay**: tape delay 1/4 note, very subtle (10–15% mix)
- **NO mastering compression nặng** — giữ dynamic range tự nhiên

## 7. Vocal style (khi có vocal)

- **Hầu hết lo-fi KHÔNG có vocal** — instrumental dominant
- **Vocal chop**: sample vocal ngắn (2–4 syllable) từ jazz/soul record, lặp loop, pitch down
- **Dialogue sample**: clip phim anime, old movie, speech — đặt ở intro/outro hoặc transition
- **Nếu có vocal thật**: nữ close-mic, whisper-soft, reverb heavy, LP filtered. Very rare.

## 9. DON'T

- KHÔNG master loud (−6 LUFS) — lo-fi PHẢI giữ dynamic (−16 đến −12 LUFS).
- KHÔNG dùng synth super-polished/bright — lo-fi = warm, muted, analog.
- KHÔNG sidechain pump — cảm giác "phẳng êm", không EDM pumping.
- KHÔNG tạo structure phức tạp (verse-chorus-bridge) — lo-fi = loop, đơn giản.
- KHÔNG hi-hat straight quantized — PHẢI swing + humanize velocity.
- KHÔNG bỏ vinyl noise / tape warmth — đây là aesthetic core.
- KHÔNG để track dài quá 3:00 — lo-fi thường ngắn, playlist-friendly.
