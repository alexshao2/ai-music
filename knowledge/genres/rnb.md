# R&B — Cookbook đầy đủ

R&B (Rhythm and Blues) trải qua nhiều kỷ nguyên: classic R&B 1940–60s (Ray Charles, Sam Cooke),
Motown 60s–70s (Stevie Wonder, Marvin Gaye), New Jack Swing 80s (Teddy Riley), 90s golden-era
(TLC, Aaliyah, Boyz II Men, R. Kelly, D'Angelo), 2000s pop-R&B (Usher, Beyoncé, Alicia Keys),
và contemporary/alternative R&B 2010+ (The Weeknd, Frank Ocean, SZA, Daniel Caesar, H.E.R.).
File này focus **contemporary R&B (2010–2025)** — dòng chính hiện tại.

## 1. Tham số âm thanh

| Tham số | Giá trị |
|--|--|
| Tempo | 60–100 BPM. Slow vibe 60–75 (The Weeknd "Call Out My Name"); mid 80–100 (SZA "Kill Bill") |
| Time sig | 4/4 (~95%); 6/8 hiếm (ballad slow) |
| Key | Minor dominant ~65% (Cm, Em, Fm, Abm, Bbm); major cho upbeat/feel-good (D, Eb, F) |
| Vocal range | Nữ A3–F#5 (SZA, Beyoncé belt); nam B2–A4 (The Weeknd falsetto Bb4–E5) |
| Master loudness | −8 đến −6 LUFS (streaming) |
| Sub bass | 808 sub hoặc synth sub bass; thường glide + saturation |

## 2. Cấu trúc bài (form)

```
Intro (4–8 bar, ambient pad hoặc vocal snippet)
→ Verse 1 (8–16, vocal intimate/talk-sing)
→ Pre-chorus (4–8, build subtle)
→ Chorus (8–16, melodic hook + vocal stack)
→ Post-chorus / Tag (4–8, repeat hook line)
→ Verse 2 (8–16)
→ Pre-chorus → Chorus
→ Bridge (8, vocal showcase hoặc beat switch)
→ Final Chorus (16, layered ad-libs + counter-melody)
→ Outro (4–8, vocal fade hoặc 808 tail)
```

**Đặc điểm contemporary R&B**:
- Post-chorus thường xuyên — repeat hook 2–4× tạo earworm
- Bridge thường **strip-down** hoặc **half-time**
- Final chorus KHÔNG modulate — thêm vocal layers thay vì transpose

## 3. Vòng hợp âm điển hình

| Tên vòng | Pattern | Cảm xúc |
|--|--|--|
| Neo-soul cycle | ii9–V7–Imaj7–vi7 | Dm9–G7–Cmaj7–Am7. Smooth, jazzy. Staple. |
| Minor groove | i7–iv7–bVII7–bIIImaj7 | Cm7–Fm7–Bb7–Ebmaj7. Dark, sensual. |
| Dorian vamp | i7–IV7 (loop) | Em7–A7 (2 chord loop). Groove-based. |
| Gospel-soul | I–iii–IV–iv | C–Em–F–Fm. Major-to-minor borrowing. Uplifting → bittersweet. |
| Weeknd signature | i–bVI–bIII–bVII | Fm–Db–Ab–Eb. Anthemic minor. |
| Frank Ocean modal | Imaj7–bVIImaj7–IVmaj7 | Fmaj7–Ebmaj7–Bbmaj7. Dreamy, floating. |
| SZA alt-cycle | i–v–bVI–IV | Am–Em–F–D (modal mix). Bittersweet. |

**Voicing**: extended chord (7th/9th/11th/13th) là bắt buộc. Triad nghe quá "pop". Dùng **drop-2** voicing trên keys, **slash chord** cho bass movement.

## 4. Phối khí per section

| Section | Lớp âm thanh |
|--|--|
| Intro | Ambient pad + reverse reverb + vocal snippet pitched. Hoặc Rhodes/Wurlitzer intro. |
| Verse 1 | Rhodes/Wurlitzer chord block (Juno pad layer mỏng), 808 sub đơn, hi-hat 1/16 swing 55–65%, finger snap/clap on 2+4. Vocal close-mic intimate. |
| Pre-chorus | Add synth pad (high strings hoặc choir pad), 808 thêm movement (root→5th), hi-hat roll tăng dần. |
| Chorus | Full 808 glide + kick layer, snare/clap, Rhodes mở voicing, BG vocal stack 3–4 part, occasional synth lead counter-melody. |
| Post-chorus | 808 + vocal chop loop + minimal keys. "Moment" section. |
| Verse 2 | Thêm element: guitar clean (Strat/Tele neck pickup) hoặc plucked synth, subtle percussion (shaker, tambourine). |
| Bridge | Strip-down: 808 off, chỉ keys/pad + vocal. Hoặc beat switch half-time với new texture. |
| Final Chorus | Vocal stack 4–6 layers + ad-lib runs + counter-melody synth/guitar + hi-hat double-time. |
| Outro | 808 sustain fade + Rhodes tail + vocal whisper/ad-lib mờ dần. |

**Drum palette**: 808 kick (long decay, slight distortion), clap/snap layer, hi-hat programmed 1/16 with swing, occasional live drum loop underneath.

## 6. Vocal style

- **Falsetto / head voice** prominence — The Weeknd, Daniel Caesar, Frank Ocean sử dụng falsetto làm weapon chính
- **Vocal runs / melisma** 4–8 nốt ở cuối phrase và ad-lib (Beyoncé, SZA)
- **Talk-singing** ở verse: nửa nói nửa hát, rhythmic nhưng pitch vague (Drake influence)
- **Layered vocal stack**: lead + octave below + 3rd above + 5th above ở chorus. 4–8 track minimum.
- **Breathy / intimate** close-mic ở verse — audible breath, minimal compression
- **Ad-libs**: "oh", "yeah", "baby", "mmm" — scattered behind chorus, ramping ở final chorus
- **Reverb**: plate 1.2–1.8s; delay 1/4 dotted on ad-libs
- **Auto-tune**: light pitch correction (NOT T-Pain style) — transparent tuning

## 7. Lyric idiom

- **Theme**: love (sensual, conflicted, toxic), heartbreak, self-reflection, late-night vibes, intimacy, longing, empowerment
- **Tone**: intimate, conversational, emotional vulnerability
- **POV**: first-person dominant ("I" / "me"), direct address ("you")
- **Imagery**: neon lights, city nights, bedroom, silk sheets, champagne, 3AM texts, driving at night
- **Phrasing**: longer phrases (10–14 syllables) with swing placement
- **Code-switching**: minimal slang; R&B lyrics tend to be poetic but accessible
- **Hook**: melodic, singable, 4–8 words repeated. Often a question or confession.
- **Contrast**: verse vulnerable → chorus powerful/declarative

## 8. Suno style tag template

Moody contemporary R&B:
```
contemporary r&b, neo-soul, 78 bpm, e flat minor, rhodes piano, 808 sub bass glide,
programmed hi-hats with swing, breathy intimate male falsetto vocal, layered vocal
harmonies, ambient synth pad, late-night mood, smooth groove
```

Upbeat R&B:
```
upbeat r&b, 95 bpm, f major, funky electric guitar, 808 drums, finger snaps,
soulful female vocal with runs, gospel chord progression, feel-good vibe, summer
```

## 9. DON'T

- KHÔNG dùng triad đơn giản — R&B cần extended chord (7/9/11/13).
- KHÔNG để vocal flat/monotone — R&B vocal cần dynamic range + melisma.
- KHÔNG quá aggressive compression — R&B cần breathing room, subtlety.
- KHÔNG nhầm R&B với pop ballad — R&B groove-based (swing, pocket), pop ballad straight beat.
- KHÔNG bỏ 808 sub — đây là foundation của contemporary R&B.
