# Metal — Cookbook đầy đủ

Metal (heavy metal) sinh ra từ **hard rock + blues rock** cuối 1960s–1970s (Black Sabbath, Led
Zeppelin, Deep Purple). Phát triển thành hàng chục subgenre: **thrash metal** (Metallica, Megadeth,
Slayer), **death metal** (Death, Cannibal Corpse), **black metal** (Mayhem, Burzum), **nu-metal**
(Linkin Park, Korn, Slipknot), **metalcore** (Killswitch Engage, Parkway Drive, Bring Me the
Horizon), **progressive metal** (Dream Theater, Tool, Gojira), **djent** (Meshuggah, Periphery,
Animals as Leaders). File này cover CÁC DÒNG PHỔ BIẾN NHẤT cho sáng tác.

## 1. Tham số âm thanh

| Tham số | Giá trị |
|--|--|
| Tempo | 90–220 BPM. Ballad metal 70–90; mid-tempo groove 100–130; thrash 170–220; blast beat 180+ |
| Time sig | 4/4 (~70%); odd time sig phổ biến: 7/8, 5/4, 6/8 (prog metal); polymetric (djent) |
| Key | Minor / diminished dominant ~90%. Power chord root + 5th (no 3rd) = ambiguous minor. E standard, Drop D, Drop C, Drop B tuning |
| Vocal range | Clean: nam C3–A4 (tenor); screaming: không giới hạn pitch traditional; nữ B3–D5 (Spiritbox) |
| Master loudness | −6 đến −4 LUFS (VERY LOUD, brick-wall limited) |
| Guitar tuning | Standard E (classic), Drop D (nu-metal), Drop C / C# (metalcore), Drop B / A (djent, deathcore) |

## 2. Cấu trúc bài (form)

### Traditional / thrash metal
```
Intro (4–8, guitar riff hoặc ambient lead-in)
→ Verse 1 (8–16, palm-muted riff + vocal)
→ Pre-chorus (4–8, build)
→ Chorus (8–16, vocal hook + open chords)
→ Verse 2 (8–16)  →  Pre-chorus  →  Chorus
→ Solo section (16–32, guitar solo over chord progression)
→ Bridge / breakdown (8–16)
→ Final Chorus (8–16)
→ Outro (4–8, riff return hoặc fade)
```

### Nu-metal / metalcore
```
Intro (4–8, noise/ambient/riff)
→ Verse 1 (8–16, rap/scream + rhythmic riff)
→ Pre-chorus (4–8)
→ Chorus (8–16, clean vocal melodic hook)
→ Verse 2 (8–16)  →  Pre-chorus  →  Chorus
→ Breakdown (8–16, half-time, heavy, crowd-mosh section)
→ Bridge (8, clean/atmospheric)
→ Final Chorus (8–16)
→ Outro breakdown / riff (4–8)
```

### Progressive metal
```
Intro (8–16, complex riff/odd time)
→ Section A (16–32, groove)  →  Section B (16, contrasting)
→ Chorus/hook (8–16)
→ Section C (new material, time sig change)
→ Solo / instrumental (16–32)
→ Recapitulation → Chorus
→ Epic outro (16–32)
```

**Breakdown**: đặc trưng metalcore/deathcore — half-time heavy section, open string chugging,
crowd mosh pit moment.

## 3. Guitar riff patterns & techniques

### Palm mute chugging (backbone metal riff)
```
e|--------------------------|
B|--------------------------|
G|--------------------------|
D|--0-0-0-0-0-0-0-0---------|  (palm muted power chord, Drop D)
A|--0-0-0-0-0-0-0-0---------|
D|--0-0-0-0-0-0-0-0---------|
```

### Thrash gallop (Metallica "Master of Puppets")
```
Rhythm: 1/8 - 1/16 1/16 - 1/8 - 1/16 1/16 (gallop pattern)
Feel:   DUN da-da DUN da-da DUN da-da DUN
```

### Djent syncopation (Meshuggah style)
```
Pattern: X . . X . X . . X X . X . . X .   (polymetric against 4/4 drums)
```

### Power chord voicing
```
Root + 5th (no 3rd): E5 = E-B, A5 = A-E
With octave: E5 = E-B-E
Drop tuning advantage: barre with 1 finger across 3 strings
```

## 4. Vòng hợp âm điển hình

Metal dùng **power chord** (root + 5th, no 3rd) — tránh major/minor distinction:

| Tên | Pattern | Ví dụ |
|--|--|--|
| Minor power | i–bVI–bVII | Em–C5–D5. Standard metal. |
| Tritone evil | i–bV | E5–Bb5. Diabolus in musica — evil sound. |
| Phrygian dark | i–bII–bIII–i | Em–F5–G5–Em. Very dark, Middle Eastern feel. |
| Thrash descent | i–bVII–bVI–V | Em–D5–C5–B5. Descending minor. |
| Nu-metal groove | i riff (single chord vamp) | Drop D open string riff. Rhythm > harmony. |
| Metalcore | i–bVI–IV–bVII | Am–F5–D5–G5. Melodic metalcore. |
| Prog metal | i–bVII–IV–bVI | Odd-bar phrasing over standard chords. |
| Harmonic minor | i–bII–V | Em–F5–B5. Neoclassical (Yngwie). |

**Harmonic minor scale** rất phổ biến trong metal lead guitar (Yngwie Malmsteen, neoclassical).
**Phrygian dominant** (1 b2 3 4 5 b6 b7) cho Middle Eastern/dark feel.

## 5. Phối khí per section

| Section | Lớp âm thanh |
|--|--|
| Intro | Clean guitar arpeggio (reverb + delay) hoặc distorted riff count-in. |
| Verse | Rhythm guitar (palm-muted, heavy distortion, tight), bass guitar (follow root), drums (kick-snare-hat pattern, double kick optional), vocal (scream/rap/clean). |
| Pre-chorus | Guitar opens up (sustained chords thay palm mute), drums build (tom fills, double kick accelerate). |
| Chorus | Open power chords (sustained, wide), melodic guitar lead, full drums (crash on 1, ride constant), clean vocal hook, bass follows guitar root. |
| Solo | Lead guitar (distortion + delay + reverb), rhythm guitar underneath, drums groove, bass follows chord. |
| Breakdown | Half-time: guitar open-string chug (chugging 1/8 or 1/16), bass same, kick on every chug hit, snare half-time on 3. Heaviest moment. |
| Bridge | Clean: acoustic/clean guitar, no distortion, atmospheric pad/strings, soft vocal. Contrast. |
| Outro | Return to main riff, accelerando, hoặc feedback + noise fade. |

**Guitar tone**: high-gain distortion (Mesa Boogie Dual Rectifier, 5150, Axe-Fx), tight low end
(gate + EQ cut <80 Hz), scoop mids (nu-metal) hoặc mid-focused (modern metal).

**Bass**: follow guitar riff (locked), distortion/overdrive, finger or pick.

**Drums**: double kick pedal essential (thrash 16th notes), blast beat (extreme metal: kick+snare
1/16 alternating), china cymbal accent.

## 7. Vocal style

### Screaming / harsh vocals
- **Growl** (death metal): low, guttural, unintelligible. Diaphragm-driven.
- **Scream** (metalcore): mid-range harsh, more intelligible. Fry scream hoặc false chord.
- **Shout** (thrash): aggressive but pitched, semi-melodic (James Hetfield).
- **Pig squeal** (deathcore): very high-pitched inhale scream.

### Clean vocals
- **Power vocals**: high tenor belt, operatic (Bruce Dickinson, Rob Halford)
- **Melodic hook**: chorus clean melodic singing (Linkin Park Chester, BMTH Oli Sykes transition)
- **Rap-metal**: rhythmic rap delivery ở verse (Linkin Park Mike, Korn Jonathan)

### Mixing styles
- **Clean verse → scream chorus** (metalcore common)
- **Scream verse → clean chorus** (nu-metal common)
- **Dual vocalist**: 1 clean + 1 screamer (Linkin Park model)
- **Reverb**: hall 1.5–2.5s (atmospheric); room 0.5s (tight, aggressive)
- **Compression**: heavy 6:1+; vocal forward in loud mix

## 8. Lyric idiom

- **Theme**: anger, pain, rebellion, inner demons, social criticism, war, death, empowerment, resilience, existential dread, anti-establishment
- **Tone**: intense, aggressive, philosophical (prog), visceral, cathartic
- **Imagery**: fire, blood, darkness, chains, war, storm, falling, rising, battle
- **Hook**: powerful, anthemic ("NOTHING ELSE MATTERS", "IN THE END", "NUMB")
- **Verse**: descriptive, building tension, often darker imagery
- **Profanity**: acceptable but not required — depends on subgenre
- **Prog metal lyrics**: abstract, conceptual, philosophical, literary references

## 10. DON'T

- KHÔNG dùng clean guitar tone xuyên suốt — metal CẦN distortion/overdrive.
- KHÔNG bỏ double kick — essential cho metal drumming.
- KHÔNG để bass ẩn — bass trong metal phải audible, follows guitar riff.
- KHÔNG major key / happy chord — metal dominant minor/power chord/diminished.
- KHÔNG skip breakdown trong metalcore — đây là climax moment.
- KHÔNG auto-tune on screaming — harsh vocal cần natural, raw.
- KHÔNG nhầm tempo: metal nhanh (180 BPM) nhưng CÓ THỂ half-time feel (90 groove).
