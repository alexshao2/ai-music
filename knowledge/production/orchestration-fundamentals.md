# Orchestration Fundamentals

Orchestration = nghệ thuật phân chia notes của hợp âm và melody cho từng nhạc cụ trong dàn
nhạc. Đây là kiến thức nền cho:
- Classical / cinematic compositions (Hans Zimmer, Einaudi, John Williams)
- Pop ballad có string section (Adele, V-pop ballad)
- K-pop / J-pop ballad final chorus (modulate +1 với string section build)
- Bolero VN (string section background pad)

## 1. String section — voicing rules

### Range tham chiếu

| Section | Range | Sweet spot |
|--|--|--|
| Violin 1 | G3-E7 | C4-A6 (most expressive) |
| Violin 2 | G3-A6 | G4-D6 |
| Viola | C3-E6 | C4-G5 |
| Cello | C2-A5 | C3-G4 |
| Double Bass | E1-G3 | E2-D3 (sounds octave lower than written) |

### Voicing patterns

#### Pattern 1: Octave doubling (full unison sound)

```
Vln1: C5 (chord top, melody)
Vln2: C5 (unison with Vln1 — full sound)
Vla:  C4 (octave below, alto bridge)
Cello: C3 (octave bass)
Bass: C2 (octave below cello)
```

→ Used for **dramatic unison** (Hans Zimmer "Time", action moment)

#### Pattern 2: Open voicing (lush warm)

```
Vln1: G5 (chord 5th top)
Vln2: E5 (chord 3rd middle)
Vla:  C5 (chord root middle-low)
Cello: G3 (chord 5th bass register)
Bass: C2 (chord root bass)
```

→ Used for **lush ballad** (Adele "Someone Like You" string section)

#### Pattern 3: Close voicing (compact)

```
Vln1: G5
Vln2: E5
Vla:  C5
Cello: A4
Bass: F2 (octave below cello F)
```

→ Used for **chamber music** intimate

#### Pattern 4: Drone (cinematic Hans Zimmer)

```
Vln1+Vln2: A5 sustained drone (no movement)
Vla: A4 octave below
Cello: A2 octave deep
Bass: A1 octave deeper
+ ostinato pattern in cello/viola
```

→ Used for **cinematic tension** (Inception "Time", Interstellar "Cornfield Chase")

### String section — rule of thumb

- **Vln1 = lead melody** (top voice)
- **Vln2 = harmony 3rd or 5th below Vln1** (or unison for power)
- **Vla = bridge alto** (between Vln2 and Cello, fills middle)
- **Cello = tenor bass** (counter-melody hoặc octave below Vla)
- **Double Bass = octave below Cello** (foundation; sounds 1 octave lower than written)

## 2. Brass section — voicing

### Range tham chiếu

| Section | Range | Sweet spot |
|--|--|--|
| Trumpet 1 (B♭) | E4-D6 | G4-G5 |
| Trumpet 2 (B♭) | E4-D6 | G4-G5 |
| Trumpet 3 (B♭) | E4-C6 | E4-E5 |
| French Horn (F) | F2-F5 | C3-C5 |
| Trombone | E2-F5 | A2-A4 |
| Bass Trombone | C2-A4 | C2-G3 |
| Tuba | F1-F4 | F1-F3 |

### Brass fanfare voicing (signature John Williams)

```
Trumpet 1: G5 (chord 5th)
Trumpet 2: E5 (chord 3rd)
Trumpet 3: C5 (chord root)
Horn 1: G4 (chord 5th)
Horn 2: E4 (chord 3rd)
Trombone 1: C4 (chord root)
Trombone 2: G3 (chord 5th, octave below Horn 1)
Bass Trombone: C3 (chord root, octave bass)
Tuba: C2 (chord root, deep bass)
```

→ Full chord across 4 octaves, every note doubled at least 2×.

### Brass pad (background)

```
Horns 1+2: sustained chord G4 + E4 (warm pad foreground)
Trombones: sustained chord C4 + G3 (pad)
Tuba: root C2 sustained
```

→ Used for **pad** under strings/winds melody.

## 3. Woodwind section — voicing

### Range tham chiếu

| Instrument | Range | Sweet spot |
|--|--|--|
| Piccolo | D5-C8 | D6-A7 |
| Flute | C4-D7 | D4-G6 |
| Oboe | B♭3-A6 | C4-D6 |
| English Horn | E3-A5 | A3-C5 |
| Clarinet (B♭) | E3-C7 | E3-G6 |
| Bass Clarinet | D2-G5 | E2-G4 |
| Bassoon | B♭1-E5 | C2-C4 |
| Contrabassoon | B♭0-G3 | B♭0-D2 |

### Woodwind solo placement

- **Flute** = lyrical lead, ornaments, fast 1/16 runs (e.g. "Princess Mononoke" theme)
- **Oboe** = melancholic solo voice (cinematic emotional, "Schindler's List")
- **English Horn** = darker oboe, somber (e.g. "Largo from New World Symphony")
- **Clarinet** = versatile, jazz/klezmer/folk
- **Bassoon** = comedic / character ("Rite of Spring" opening), or dark bass solo

### Woodwind chord voicing

```
Flute 1: G6
Flute 2: E6
Oboe: C6
Clarinet 1: G5
Clarinet 2: E5
Bassoon: C4
Contrabassoon: C3
```

→ Used for **woodwind chorale** moment (Stravinsky-inspired pop ballad bridge).

## 4. Harp — chord arpeggio voicing

### Range
- C1-G7 (47 strings standard concert harp)
- Pedal harp can change strings to natural/flat/sharp dynamically

### Arpeggio voicing patterns

#### Pattern 1: Ascending chord arpeggio (1/16 ornament)

```
Beat 1: C2 (bass)
Beat 1.5: G2 (5th)
Beat 1.75: C3 (root)
Beat 2: E3 (3rd)
Beat 2.5: G3 (5th)
Beat 2.75: C4 (root octave)
Beat 3: E4 (3rd)
Beat 3.5: G4 (5th)
Beat 3.75: C5 (root)
... (continuing 1/16 sextuplet)
```

→ Used for **fairy-tale moment** (Disney "Beauty and the Beast", Tchaikovsky)

#### Pattern 2: Glissando

```
Quick chromatic sweep across all strings:
C1 → C7 (ascending, ~1 second across 6 octaves)
```

→ Used for **emotional swell** (transition between sections)

## 5. Percussion — orchestral

### Timpani (signature cinematic)

- 4 drums tuned to chord roots (typical: F2, G2, A2, B♭2 or transpose)
- Roll: trill 1/16 → 1/32 BB tension build
- Hits on strong beats 1 + 3 (cinematic march)
- Used for **dramatic build** or **fanfare punctuation**

### Cymbal swell

- Crescendo over 4-8 bar with brush sticks
- Climax: hard hit on downbeat ff
- Used for **tension release** (hit at climax)

### Tam-tam (large gong)

- Single hit + sustain (rings 30+ seconds)
- Used for **shock moment** or **end of section**

### Snare drum (military)

- Roll 1/32 sustained
- Used for **military / heroic theme** (Star Wars Imperial March)

## 6. Pop ballad string arrangement

### Verse: minimal (sparse intro)
- Cello + Double Bass = bass foundation (sustained)
- Viola = inner voice (sustained chord)

### Pre-chorus: build
- Add Violin 2 (sustained)

### Chorus: full
- Vln1 = lead melody (countermelody to vocal)
- Vln2 = harmony 3rd below Vln1
- Vla = sustained chord bridge
- Cello = bass + counter
- Bass = octave foundation

### Final chorus: lush peak
- Add **brass pad** (Horns sustained, low)
- Add **harp arpeggio** 1/16 ornament
- Strings full ensemble
- Timpani roll build → cymbal crash on downbeat

## 7. Voicing rules of thumb

| Rule | Description |
|--|--|
| **No chord top crowding** | Vln1 lead has space; max 1 unison voice (Vln2) |
| **Bass stays simple** | Cello + Bass = octave on root only; NO chord stacking bass |
| **Inner voices smooth** | Vla, Vln2 inner voice move stepwise (not big leaps) |
| **Doubling for power** | Octave doubling = full sound (Vln1+Vln2 unison); used sparingly |
| **Spread voicing for warmth** | Wide gaps between voices = more "open" sound |
| **Close voicing for tension** | Voices close together = more dense/intimate |
| **Brass adds at climax only** | Brass = "color burst"; reserved for chorus/final |
| **Harp = ornament not foundation** | Harp adds sparkle; piano/strings carry harmony |

## 8. Cinematic dynamic arc — orchestration progression

```
0:00 (ppp) — solo piano OR solo cello
0:30 (pp) — add Violin 1 + Viola sustained
1:00 (p) — add Violin 2 + Cello full string section
1:30 (mp) — add flute solo countermelody
2:00 (mf) — add full strings + harp arpeggio
2:30 (f) — add brass (Horns + Trombones) pad
3:00 (ff) — full orchestra + Timpani roll + cymbal crash
3:30 (mp) — strip back, return solo piano
4:00 (pp) — final fade
```

## 9. Self-check checklist cho Arranger (orchestral)

1. ☐ String voicing chosen (octave doubling / open / close / drone)?
2. ☐ Vln1 = lead melody (top); Vln2 = harmony 3rd below or unison?
3. ☐ Vla = inner alto bridge; Cello = bass + counter?
4. ☐ Bass = octave below Cello (sounds 1 octave lower than written)?
5. ☐ Brass voicing fanfare (chord across 4 octaves doubled) cho climax?
6. ☐ Harp arpeggio chord voicing 1/16 ornament tại moments cụ thể (chorus + final)?
7. ☐ Timpani rolls cho dramatic build / cymbal crash cho climax?
8. ☐ Woodwind solo (flute lyrical / oboe melancholic) tại verse/bridge break?
9. ☐ Dynamic arc ppp → ff → pp progressing throughout?
10. ☐ Ranges within feasible (no Vln1 below G3, no Cello above A5, etc.)?
